
Key combinations

~~~ vim
- or F7   = open Oil in float mode, ctrl-c = close
leader yp.. = copy/paste using system clipboard

<leader>n = new tab
<leader>x = close close
<leader>1 = go to tab 1

<leader>- = :sp = split
<leader>| = :vsp = vertical split


<leader> ;  # buffers
<leader><leader> = toggle between buffers

zz          # center current line in the center of the screen
zt          # center current line in the top of the screen
zb          # center current line in the bottom of the screen

<leader> w  # Easy search by Word
<leader> l  # hjkl easymotion search
space f # search for 1 char easymotion
space s # search for 2 chars easymotion
sab         # search for ab. ; next ctrl-o origin. Sneak search
C-g         # info about current file

gV          = re-select lat visual
ga          = EasyAlign

:cd c:/ # set initial folder for file searc.
space y # ydp = copy/paste "+y
~~~
